# 出厂固件使用说明

[English](USER_GUIDE.md) | [简体中文](USER_GUIDE_ZH.md)

## 开始使用

使用 USB 数据线为 ESP32-S3-Touch-LCD-3.5 或带外壳的 ESP32-S3-Touch-LCD-3.5-C 供电。恢复出厂软件请参照[固件烧录说明](../../firmware/README_ZH.md)，从源码构建请参照[出厂工程说明](README_ZH.md)。

桌面采用 320 × 480 竖屏，共三页，左右滑动切页；Settings 排第一，AIChats 排第二。大部分应用可点返回箭头退出；相册从屏幕底边向上滑动返回。触摸测试也可按 BOOT 退出。

短按 PWR 按键一次开机，长按 5 秒关机。启动完成后，屏幕亮起并显示桌面。

## 连接 Wi-Fi

设备支持 2.4 GHz Wi-Fi。优先使用已保存的账号；没有保存时，尝试连接演示热点 `weather-wifi`，密码 `12345678`。

1. 连接其他网络时，打开 **Settings → Wi-Fi setup**。
2. 扫描界面二维码，或手动连接屏幕显示的设备热点，密码为 `12345678`。
3. 保持连接设备热点，在浏览器打开 `http://192.168.4.1`，填写路由器的 Wi-Fi 名称和密码并提交。
4. 等待网页及设备显示连接结果，成功后保存账号。

**Wi-Fi scan** 只查看附近网络的名称、信号强度、加密方式和信道，不会连接选中的网络。

设备能够访问互联网后，通过网络校时更新桌面时间，时区为 UTC+8。Sensor 应用显示的硬件 RTC 时间独立保留。

## 准备 SD 卡

使用 FAT32 格式的 microSD 卡，在卡的根目录建立以下文件夹，再插入设备：

```text
/photo/       JPEG 照片（.jpg 或 .jpeg）
/music/       MP3 音乐（.mp3）
```

建议使用 320 × 480 的 JPEG 图片，以加快加载。添加图片后，重新打开 Photos 查看。取卡前请先退出正在使用 SD 卡的应用。

## 应用操作

| 应用 | 操作 |
| --- | --- |
| Settings | 调节屏幕亮度和音量，扫描 Wi-Fi、配网、查看 SD 卡信息和 About。 |
| AIChats | 联网后，按屏幕显示的激活码和提示完成激活；说“你好小智”或点 **Talk** 开始对话。询问摄像头看到的内容可调用拍照与视觉分析，拍摄画面会显示在屏幕上。 |
| Touch Test | 在屏幕上绘画检查触摸覆盖范围；点左上角返回按钮或按 BOOT 退出。 |
| Photos | 浏览 `/photo` 中的 JPEG；左右滑动换图，从底边向上滑动退出。 |
| Weather | 连接互联网后查看天气信息。 |
| Music | 播放 `/music` 中的 MP3，支持上一首、下一首和播放/暂停切换；音量在 Settings 调整。 |
| Sensor | 查看硬件 RTC 时间及 QMI8658 加速度、陀螺仪数据。 |
| 2048 | 滑动合并数字，点 **New** 重新开始。 |
| Camera | 查看摄像头预览，按 BOOT 旋转 180°；插入 SD 卡后，点 **Capture** 将照片保存到 `/photo`，随后可在 Photos 浏览。 |
| Mic Test | 不插卡也可查看麦克风音量变化；插卡后点 **Record** 开始录音，最多录制 10 秒，点 **Stop** 可提前结束，再点 **Play** 回放最近一段录音。文件保存在 `/recordings`。 |
| Button Test | 分别短按并松开 BOOT、PWR，查看按键状态、次数和 PASS 结果；点 **Test again** 重新测试。测试 PWR 时请短按，避免触发关机。 |
| Display Test | 点击五色色带显示器图标，红、绿、蓝、黄、白全屏颜色每秒循环；任意颜色下双击屏幕任意位置即可返回桌面。 |

Button Test 只在打开时检测按键，完整按下并松开后才计数。进入页面或点重新测试时已经按住的按键，须先松开再按一次。PWR 的原有长按关机功能保留，测试时请短按；用屏幕左上角返回按钮退出测试。

Music、Mic Test 和 AIChats 独占共用音频设备，切换前先退出当前音频应用。

## 常见问题

- **Wi-Fi 已连接，但天气或小智不可用：**确认热点能够访问互联网；连上热点不代表远端天气或语音服务一定能访问。
- **桌面时间未显示：**等待网络校时，检查网络及 UDP/NTP 是否可用；该过程不会修改 Sensor 的硬件 RTC。
- **相册或音乐没有文件：**检查卡的格式、文件夹名称和文件扩展名；添加文件后重新打开应用。
- **AIChats 提示缺少语音模型：**烧录完整工程或出厂合并镜像，包含语音模型分区；单独烧录 APP BIN 不会安装模型。
- **提示音频占用：**退出正在使用的 Music、Mic Test 或 AIChats，再重新打开需要的应用。
- **相机有预览，但 AI 分析失败：**检查网络和视觉服务返回结果，本地拍摄和远程分析是两个步骤。
