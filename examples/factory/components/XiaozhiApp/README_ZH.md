# AIChats 组件

[English](README.md) | [简体中文](README_ZH.md)

## 功能

将小智激活、唤醒词、语音对话与摄像头识别接入 Brookesia 应用生命周期。[出厂工程](../../README_ZH.md)将本组件安装为 AIChats。

## 硬件需求

使用本板 ES8311 与单麦克风，没有硬件回声参考通道。摄像头识别与独立 Camera 应用共用 BSP 的摄像头驱动及互斥锁。

## 怎么运行

完整编译、烧录出厂工程，包含语音模型分区。在 Settings 配置网络，打开 AIChats 完成激活，说“你好小智”或点击 Talk 开始对话，点击 Stop 取消。

## 预期现象

识别文本和回复通过字幕、音频输出。服务端调用摄像头工具时，界面显示本地预览及分析中的照片；BOOT 可为下一次拍照切换 180 度方向，离开摄像头视图后恢复对话布局。

## 常见问题

摄像头识别需要服务端下发视觉服务配置，串口分别报告采集、上传与服务错误。图像和音频缓冲使用 PSRAM，MCP 工作任务栈保留在内部 RAM，以支持可能关闭外部存储缓存的 NVS 操作；上游 OGG 适配代码的来源及 MIT 许可证保留在 [third_party/xiaozhi_esp32](third_party/xiaozhi_esp32/)。
